# Submission video

`CEDRUS_2min.mp4` (1:59.5, 1080p) is too large for the repository; it is attached to the GitHub release instead.

- `scripts/`: frame-exact Playwright recorders of the app, the audio build and the final compose (`timeline.py` is the edit list).
- `overlay/overlay.html`: captions, cards, the proof chart and the flame mascot rig.
- `mascot/`: the team's flame drawing, cut out, plus its rig.
- `CREDITS.txt`, `footage/SOURCES.txt`: NASA SVS footage, music (Scott Buckley, CC BY 4.0), ElevenLabs narration (AI voice), data sources.
- `CEDRUS_2min.srt`: subtitles.
